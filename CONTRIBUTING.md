# Contributing to NoteUp

Thank you for your interest in contributing to NoteUp! 🎉

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/NoteUp.git
   cd NoteUp
   ```
3. **Create a branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Make your changes** and test thoroughly:
   ```bash
   npm run build
   ```
5. **Commit your changes**:
   ```bash
   git commit -m "feat: add support for XYZ"
   ```
6. **Push to your fork** and submit a **Pull Request**.

## Design Guidelines

- NoteUp follows a clean, document-first **Notion Design Language**.
- Avoid loud neon gradients or heavy drop shadows.
- Keep the UI responsive, accessible, and fast.
